# 🎵 Spotify Clone

A simple Spotify clone built using HTML, CSS, and JavaScript. This project mimics the UI and basic functionality of Spotify, allowing users to interact with music files in a clean and responsive interface.

# 🚀 Features

- 🎧 Audio player with custom controls
- 🖼️ Artist images and thumbnails
- 🎨 Responsive design
- 📁 Organized folder structure with separate `audio`, `img`, `css`, and `js` files

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
